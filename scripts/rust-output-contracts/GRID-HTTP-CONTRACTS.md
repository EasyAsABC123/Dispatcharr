# Guide HTTP component gate

All application credit remains with the original Dispatcharr authors and contributors. This port follows their `apps/epg/api_grid.py` behavior under the existing AGPL license.

Current packaged scope: image25 attaches `/api/epg/grid/` and passes43 actual original/network comparisons with unchanged real clocks, exact complete bodies and selected application middleware headers; see `verified-grid-packaged-image25-1.json`. The preceding Source/native component gate `verified-grid-network-native-28.json` also passes those43 cases. The negotiation corpus ran:146 JSON status/body/MIME cases match, and six original browsable-HTML error cases remain explicit unsupported501 responses. OPTIONS metadata and method-level permissions are implemented. Custom dummy rules, broader negotiation grammar, offset-sensitive dummy windows, concurrent-refresh consistency, populated guide browser workflows and full guide performance remain open. The historical native1 description below records its narrower original scope.

`verified-grid-http-native-1.json` binds a frozen post-image24 component to its tools and raw evidence. Forty original APIRequestFactory cases match independent native network responses in status, complete body bytes, and MIME type. The original Factory manually consumes HEAD entities, so that is not used to infer network HEAD behavior: one separate actual request to the original HTTP server verifies the empty HEAD body and headers. No original-network GET clock-stability or packaged app acceptance is claimed.

The cases include admin, standard, profile-filtered, basic, inactive, and anonymous users; explicit and unknown profiles; duplicate query arguments; valid and invalid windows; stored programmes; and standard dummy guides. Selected `Allow` and `WWW-Authenticate` headers match where supplied by the original response. Original outer middleware headers are outside this independent-router gate.

Admission occurs before authentication, cached settings, and SQL. Each physical operation reserves 96MiB within a default shared192MiB budget and two-operation limit. A logical five-second deadline does not cancel physical SQL cleanup or release admission early. The disposable PostgreSQL test observes a real table lock wait, then verifies caller abort, deadline expiry, excess-request rejection, and shutdown waiting until rollback completes. No simulated database substitutes for this test.

Completed responses release physical-operation admission and retain a shared byte lease charged against actual vector capacities plus bounded bookkeeping. Retained frames can outlive shutdown; a final-clone test verifies their byte lease persists and returns only when the final clone drops. Query/header inputs are bounded before decoding/copying, and frame count/retained memory are bounded. Resource limits return explicit503 instead of omitting programmes.

At the historical native1 checkpoint the router was app-unwired and OPTIONS/negotiation/network attachment remained open. The later gates described above supersede those implementation gaps within their captured scopes. No performance claim follows from these functional tests.

```
source artifacts/rust/tooling/environment.sh

```
