# Executable Original evidence links

Original Dispatcharr authors retain all application/algorithm credit and licensing.

`source-links.json` links committed, reviewed Original captures to the unchanged
contract register. It contains35 actual plugin TCP cases on seven exact route
identities,166 passive framework metadata observations and three management-help
observations on their original non-HTTP candidate IDs. It includes per-case
pointers and hashes, methods, roles, response identities and evidence layers.

The adapter checks dataset hashes against their committed review attestations,
all592 resolver identities,798 operation work items and250 non-HTTP candidates.
Seventeen controls reject reordered identities, altered methods, unknown roles,
wrong paths/format aliases, nonempty HEAD bodies, fabricated TCP/native labels,
help invocations that would execute a command handle, and corrupted data/streams.
It never invokes a request or changes the register.

Reproduce from the repository root:

```sh
python3 scripts/rust-contracts/source_links.py \
  --output artifacts/rust/source-links-NEW.json
python3 -m unittest discover -s scripts/rust-contracts -p test_source_links.py -v
```

The adapter requires only committed public files and the Python standard library.
It makes no Docker/network/private-artifact calls. Regenerate the same JSON bytes
with the same inputs. Its input hash map makes later register/capture changes
visible; review new identities instead of silently reusing an old link.

These are Source-only observations. The seven routes still have unresolved
method placeholders; HEAD/OPTIONS/POST/DELETE cases are not attached as GET
acceptance. Passive allowed-method metadata does not prove HTTP, authentication
or authorization. Help captures do not execute command handles. Native parity,
complete role/input matrices and the remaining baseline scenarios stay open.
No operation is marked fully verified and M0 is not closed.
