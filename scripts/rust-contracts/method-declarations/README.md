## Reproduce

Use the six exact input digests in report.json:

    python3 -B map_declarations.py \
      --archive ORIGINAL_SOURCE_ARCHIVE \
      --register PINNED_D38_REGISTER \
      --census PUBLIC_RUNTIME_METHODS_JSON \
      --resolver-report ACTUAL_D38_RESOLVER_REDUCTION \
      --backup-options-proof ACTUAL_BACKUP_OPTIONS_QUALIFICATION \
      --account-bindings PUBLIC_ORIGINAL_ACCOUNT_SETTINGS_BINDINGS > reproduced.json
    cmp report.json reproduced.json

The public inputs are docs/rust-runtime-methods.json and scripts/rust-contracts/accounts-settings/bindings.json. The other inputs are digest-pinned retained evidence. The mapper rejects altered inputs and runs no Git, Django, SQL, or engine commands. The schema describes the portable report.
