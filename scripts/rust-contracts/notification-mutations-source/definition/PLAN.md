## Authority and order

Pinned Original1241b3f7ffb2e64c8d1157ecd5e3b199af1ae430 defines no update or destroy
override on SystemNotificationViewSet. Its IsAdmin checks persisted user level10 and
actual UI network access. Forced real active users bypass credential authentication;
this does not qualify JWT, sessions, TCP, inactive-user acceptance, middleware-wide
network policy, or a whole-stack read/dismiss network gap. Anonymous denial remains a
hypothesis with actual first-authenticator status retained. All three mutation methods
receive anonymous, standard and network-denied-admin cases, including malformed bodies.

The exact tagged DRF3.18.3 mixins place get_object before serializer validation. PUT
requires key/title/message; PATCH skips missing required fields. Model-default fields
are required=False, not serializer defaults; optional omission on PUT retains saved
values. UniqueValidator excludes the current instance. Unknown/read-only fields are
ignored, including id/created_at/is_dismissed and unexposed updated_at. The generated
serializer and effective field kwargs must be captured from the actual pinned image;
tagged upstream bytes do not alone establish image contents.

ModelSerializer.update sets validated attributes and saves once, even when validation
produces no changed fields. JSON action_data replaces its whole value, accepts JSON
arrays/scalars while source=system, and rejects null. String coercion/trim, max255,
choice enums, boolean coercion, expiry parsing/offset and null expiry are finite
normalization cases, not an exhaustive equivalence claim. Error response bytes and
field ordering are observed, not manufactured from predictions.

get_queryset applies active/expiry visibility to admin writes, including delete.
It evaluates all visible developer notices before pk filtering. H is cachedfalse,
V cachedtrue; U begins without a condition key. The first authorized missing-target

caches its result; the later U request observes that cached visibility. No evaluator/helper patch is permitted. Cache entries are
captured after subsequent update/delete; no invalidation behavior is assumed.
The last two cases intentionally demonstrate a permissible system-to-developer write
of a truthy nonobject action_data and the resulting global .get shape-error boundary.

APIClient.raise_request_exception=False and retain its actual value. If a response is

a response. Record fixture outer catches separately with phase/current case index,
actual completed count and partial report. This is not a deployed WSGI/ASGI/TCP500
claim. No corrective replay.

Successful update returns serializer.data on the saved instance. Making A inactive
or B expired can return200 and cause later writes404. id/created_at/dismissals stay
fixed. updated_at must lie in that request's raw wall-clock bounds; strict increase
and cross-engine timestamp equality are not claimed. SQL retains raw timestamps,
response bytes remain unnormalized, and future Native own-clock/ID matching must be
