2. Create the guarded fixture only in its fresh disposable database. Wrong password/guard, existing category rows, pre-existing active XC providers, duplicate namespace, nonempty content/poster tables or changed counts fail closed. Model bulk creation avoids ingestion signals; private URLs point only to the idle owned origin.
3. Independently count every Original JSON row:242 ordered categories and501 nested links. Preserve disabled/inactive/STD metadata and distinguish JSON booleans/null/numbers/strings. Capture exact raw status/MIME/length/SHA once; a JSON-equivalent reordered representation or wrong body must fail. Native cannot substitute a different query or omit nested rows.
4. Run real Original/native ten-reader barrier checks with no staggering. Confirm the shared default two-active/192 MiB VOD limits, declared Docker CPU/memory limits, source/candidate provenance and no duplicate active backend. Functional mode must not import/start sampler or observer branches.
5. Check all declared row/schema fingerprints and empty content tables before and after functional/qualification/measured phases. Flip one enabled flag, profile, user property or settings value in a disposable negative control and require rejection; restore the exact owned data before continuing. Never weaken fingerprints to accommodate a change.
6. Prove Source-only rate selection rejects incomplete rows, candidate metrics, wrong rate candidates, infeasible Original or changed workload. Source observer smoke must validate cgroup/Docker counters, service names, limits and monotonic samples before qualification. Existing idle-origin process must remain alive and report zero requests.
7. Acceptance controls reject CPU/memory regressions, completion/TTFB failures, low throughput/pacing, wrong response bytes/types, missing samples, nonfinite values, late completions, observer errors, OOM kills and counter resets. All six pairs must pass independently; aggregate medians cannot conceal a failure. A measured late_completed value above zero is always a rejection.
8. Cues gate actual execution. Source qualification ends at the frozen plan and waits; absent measurement authorization yields no native resource values. Copying historical cues or importing modules must not authorize work. Competing agent fixtures/builds must be stopped by the parent before each quiet window.
9. Cancellation/failure must stop only owned readers/observers/containers and remove that Compose project's volumes/network. Preserve the failed attempt and diagnostic records. Tokens/private row material remain in ignored private evidence; public reports contain only necessary counts, hashes, scope and outcomes.

The accepted ordinary VOD and guide controls are reusable infrastructure evidence, but this fixture/endpoint/image34 binding has now passed Source/native functional validation.
