These channel-layer messages do not establish browser WebSocket transport.

Independent cleanup proved both exact fixture CIDs, project resources and both persisted positive original host PIDs absent; the separate UID probe CID is absent, with its host generation explicitly unobserved.

Only fresh plain basic Movies/empty Series were characterized. Native implementation, updates/metadata/language/nonempty-Series/provider errors, auto-M3U child production, complete roles, full milestones and performance remain unqualified. Raw credentials, owned Origin private keys and private capture payloads are excluded.
