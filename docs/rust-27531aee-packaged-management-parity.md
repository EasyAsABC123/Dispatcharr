The Rust successor `27531aeeea69f53ebb37f33c4069bda0fd2efa8f` was built and verified on AMD64 and
ARM64. The ordinary Linux/AMD64 image was `sha256:112612e750fd41d4390d0cb38a65e7d63b5b9a387a784960db27247dc86e5f54`.

Both packages were built from the same 2,161 verified application files.

byte for byte. Fifteen focused Rust tests and the operator compile
check passed. The ARM64 package started and passed signed authentication
in an isolated Compose scope with exact teardown.
