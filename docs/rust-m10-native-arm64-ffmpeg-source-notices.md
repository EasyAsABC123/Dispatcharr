# Source and notices for Original ARM64 FFmpeg and ffprobe

The exact Original ARM64 image includes a 19,479-byte OCI layer with the build record and notices for its custom `9.0.2-Dispatcharr` FFmpeg and ffprobe binaries. The public registry returned the layer bytes by digest. The verification matched both the compressed layer digest in the manifest and the uncompressed layer digest in the image config. The build history places that layer immediately after the layer that copied both executables. The prior native probe independently recorded the executable hashes, 55 shared-library inputs per tool, and 51 installed package notices. [Native donor probe](rust-m10-native-arm64-ffmpeg-collector-inputs.md) · [Digest-bound source and notice receipt](../scripts/rust-integration/m10-native-arm64-ffmpeg-source-notices.json)

The embedded `SOURCE_REVISION` identifies Dispatcharr's public FFmpeg recipe at `fce79836385ee64bc3c91360fb9cfb40818b80c7`. The public release tag resolves to that full commit, and the corresponding upstream ARM64 build job succeeded. The release archive matched the image's FFmpeg and Intel pin files and licensing README byte for byte. The audited Dockerfile reproduces the combined pin file and records the source revision supplied by the workflow. The image also includes the configure line, GPLv3 and LGPLv3 texts, and the stripped FDK AAC notice. The actual ARM64 configuration enables GPLv3, GnuTLS, VAAPI and NVENC with the 13.0 headers. [Exact upstream release](https://github.com/Dispatcharr/FFmpeg/releases/tag/v9.0.2-nvenc130-fce79836385e) · [Upstream ARM64 build](https://github.com/Dispatcharr/FFmpeg/actions/runs/41535570927/job/125586551834) · [Embedded licensing README](https://github.com/Dispatcharr/FFmpeg/blob/fce79836385ee64bc3c91360fb9cfb40818b80c7/licenses/README.md)

The separate GHCR request for the attested historical FFmpeg builder still has a recorded anonymous HTTP 401. Its raw OCI manifest and config remain unavailable through that route. The upstream recipe identifies nine ARM64 source archives by version or revision. A fresh replacement build still needs archive checksums, signed Ubuntu toolchain and shared-library source inputs, and repeatable native decoder, encoder, and application checks. The standalone native Debian wrapper already exercised the exact Original tools on generated media. Full source and notice qualification for distributing a package containing the tools remains open.
