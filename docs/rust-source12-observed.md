These observations do not qualify arbitrary query characters, malformed or nested payloads, custom HTTP reason phrases, or all redirect behavior.

The positive search response was **381 bytes**. Its decoded values contained U+2028 and U+2029, while the actual JSON wire used ASCII `\u2028` and `\u2029` escapes. A separate read of the installed DRF3.18.3 renderer source, without Django setup or HTTP calls, bound the matching renderer behavior. This supports the bounded scalar/null search renderer; it does not claim equivalence for every possible JSON shape.
