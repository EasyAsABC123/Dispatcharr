# Stock Original signed notification read methods

One isolated stock AIO AMD64 nginx fixture ran pinned Original 1241b3f7 for 20 signed JSON requests to notification collection, count and detail. Administrator and Standard each read the three ordinary routes over GET and HEAD. The seven HEAD replies, including the Standard request for the administrator-only detail, had zero actual body bytes and the exact selected headers and declared lengths of their GET counterparts.

All three administrator OPTIONS requests returned 200. Collection metadata described POST, and detail metadata described PUT. All three Standard OPTIONS calls returned 403. Standard GET and HEAD on the separate administrator-only notification returned 404. The general notification remained visible and the read-only SQL snapshot stayed unchanged.

The inner controller and all five owned phases exited 0. Independent teardown verified retirement of the exact container and process generation with empty inventories. The audit verified the pinned manifest, receipt and unchanged SQL. HEAD and OPTIONS remain runtime observations tied to existing route IDs. The result supplies Original authority without Native acceptance, new register declarations, performance or full M0 closure.
