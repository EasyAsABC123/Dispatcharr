credit. This checkpoint preserves the existing React and license inputs.

  and response while the first worker is still setting up the session.

  reservation and verified an HTTP-domain 503 for the contender. All

  affected Rust validator tests passed.

  including six authenticated multipart requests. The Compose fixture
  shut down cleanly and its owned resources were independently removed.

  PostgreSQL 17 clients at the versions recorded by its collector.
  Compose verified both Original-to-Rust and Rust-to-Original archive
  restoration using three copied databases and twenty-six nonempty tables.
  It also checked two authentication and privilege failures. The default
  fixture database stayed unchanged.
