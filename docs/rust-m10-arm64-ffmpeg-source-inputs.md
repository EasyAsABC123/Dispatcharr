# Verified native ARM64 FFmpeg source and Ubuntu package inputs

The nine archives in the exact public Dispatcharr FFmpeg source recipe were retrieved and recorded by SHA-256. FFmpeg's release signing key verified the detached OpenPGP signature. Opus matched Xiph's published checksum, and LAME matched Canonical's signed source index. Six Git archives matched the public maintainer tags or commits recorded inside the archives. The verification retained 23 source notice or header records, including byte-identical copies of Original's FFmpeg GPLv3, LGPLv3, and stripped FDK AAC notices. The libvpx tag signature still lacks a trusted key in the receipt. [Original tool provenance](rust-m10-native-arm64-ffmpeg-source-notices.md) · [Upstream build recipe](https://github.com/Dispatcharr/FFmpeg/releases/tag/v9.0.2-nvenc130-fce79836385e)

The exact historical Ubuntu ARM64 base was recovered from Docker Official Images. The child manifest and config match both compressed and uncompressed Original base layers. Canonical's signed archive snapshot from the build time supplied all 25 exact direct runtime package versions and 36 direct build package candidates. The intake verified 89 unique Ubuntu binary archives including the signed GCC package that supplies four shared copyright files. All 51 installed notices match the prior Original probe. [Historical Docker Official Images record](https://github.com/docker-library/official-images/blob/352563ade23938429a2f55e1eb722af237c4f276/library/ubuntu) · [Ubuntu Snapshot Service](https://snapshot.ubuntu.com/) · [Original native probe](rust-m10-native-arm64-ffmpeg-collector-inputs.md)

Signed Ubuntu source indexes cover all 22 source package versions behind the 25 direct runtime packages. The private intake verified 76 of 76 corresponding-source files for those package versions. The complete recursive APT installation closure and historical installed builder versions remain unverified. A fresh native rebuild still needs that closure. Executable byte identity, full runtime parity and package distribution each have their own acceptance requirements.
