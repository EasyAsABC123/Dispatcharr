The ordinary AMD64 Rust package matched the pinned Original for
all 18 signed GET, HEAD and JSON OPTIONS cases. The comparison
covered both numeric routes and Owner, Administrator and Standard
actors. Status, body digest, Allow, Vary and the selected response
metadata matched. The read-only SQL fingerprints and both exact

its test tooling to an older parent. A fresh preparation verified
the correct parent tooling and ran the same signed cases. This
scope covers eighteen requests and leaves broader AppData
variants and full M0 and M5 acceptance open.
