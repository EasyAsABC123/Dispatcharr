# Manual commercial detection: original application reference

All application and task credit belongs to Dispatcharr's original authors. Comskip, FFmpeg and their dependency authors retain their original algorithm and library credit. This migration claims no original application or algorithm authorship.

The [actual Source run](../scripts/rust-integration/comskip-manual-source1/index.json) passes three natural admin HTTP requests: a completed recording without a file returns `no_file`; processing a real imported eight-second A/V MKV returns `no_commercials`; the subsequent request returns `already_processed`. Each request publishes one real default-queue Celery root, finishes with backend `SUCCESS` and no children, and matches the expected SQL properties and ordered channel-layer messages. The 719,267-byte input remains unchanged with SHA256 `ebcc185d00fb24ab467c0605639415061f3001ff09e1381a70420fd1aa72fd3d`. Native comparison must reuse that exact retained input rather than regenerate a Matroska container with a potentially different identifier.

The actual workflow selected `/app/docker/comskip.ini`. Its completed/skipped properties and final `no_commercials_detected` status identify the original task's exit-one branch. An empty EDL file was produced. This observation does not qualify the later FFprobe/nonempty-commercial mark path, automatic DVR publication or cut/remux processing. The [semantic contract](../scripts/rust-integration/comskip-manual-source1/contract.json) preserves all three API responses, backend results, properties, media observations and ordered updates, normalizing only owned recording identifiers and the mounted input path.

The bounded controller exited zero in 91.223 seconds with both output streams at EOF and its process group settled. Root independently verified both fixture containers, their two original positive host process IDs, the Compose project and the readability-probe container were gone. The readability probe's host process generation was not independently captured.

The Rust implementation is still awaiting its next compiled candidate and actual Native comparison. It copies the unchanged executable from the pinned original image and retains its actual binary hash, original build recipe, original default INI, GPL text and author notices. The original recipe downloads mutable upstream master and does not record the corresponding source commit; that exact revision remains unknown. This reference is not a release-ready binary/source-closure claim, a full milestone pass or an application performance measurement.
