# Copied SQLite React shell on the 2c939204 base

A private Linux AMD64 preview image used the published `2c939204` application
plus the three reviewed React shell changes. The packet preserved all 2,142
source inputs and 497 protected React and attribution files.

The pinned Original used an owned SQLite fixture with two dialect-only migration
adapters and the retained packaged React index. It served HTTP 200 for both GET
and HEAD on `/` and `/channels` before and after reopening the copy. The fresh
Native preview served the same routes through the feature-on loopback listener.
GET returned the same 858 HTML bytes and referenced the same local JavaScript
and CSS. Native served those packaged assets before and after a full Main
restart. The HTTP client checked HEAD using its method-specific response framing.

The same project verified login, profile and channel group reads, a saved App
Data update, listener shutdown, App Data readback with the original bearer
after restart, bearer refresh and deletion of the owned App Data item. Build,
Compose run and evidence verification each exited 0. Both Main generations,
Redis, the seed and the probe retired by their exact identities. An earlier
controller exited 1 before Docker because its local authority module shadowed
the inherited package-tool import. The retry retained the reviewed source and
ran a fresh image. [Scoped receipts](../scripts/rust-integration/m8-2c939204-copied-sqlite-react-shell.json)

The preview covers the React shell and local assets. Channel List JSON, full
browser workflows and the ARM64 shell remain open. The original Dispatcharr,
React, Django, SQLite, SQLx and other contributors retain full credit.
