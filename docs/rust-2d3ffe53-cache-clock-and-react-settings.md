# Current Main cache clock and ARM64 Chromium Settings

## M2 ordinary Main cache clock

An owned Redis relay held a real five-byte response for 1.377 seconds during a signed workflow on exact `2d3ffe53`. The next read performed a real cache load 10.000 seconds after the first dispatch and 8.623 seconds after its reply was forwarded. That interval distinguishes the ten-second expiry measured from the load start from one measured after reply completion. The relay and all owned resources retired. Identifying both individual ordinary HTTP waiters remains a separate formal requirement. [Redacted clock proof](../scripts/rust-integration/m2-2d3ffe53-current-main-cache-clock.json)
