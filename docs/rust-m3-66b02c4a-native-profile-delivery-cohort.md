One Compose fixture on the ordinary `66b02c4a` image passed HLS, fMP4,
and equivalent and distinct output profile delivery. It verified normal
reopen, a natural primary-to-fallback switch for two readers with one
active upstream at a time, and fresh playback after losing an owned
FFmpeg child. The second Main generation exercised the packaged VLC
profile against the same owned origin. Its actual `Range: bytes=0-`
request received HTTP 200 without Content-Range, matching the retained
Original VLC observation.

The run captured 16 useful audio and video decodes, two clean Main exits,
and exact retirement of all four owned container and process generations.
The first run passed both VLC decodes and cleanup. Its final observer
applied the FFmpeg no-Range expectation to VLC. The corrected observer
passed its physical and independent reducer phases on the same image.

This run supplies the scoped Native evidence. Formal profile-delivery
acceptance still requires the coordinator-owned row with both retained
Original dependencies. Comparative application performance remains open.
