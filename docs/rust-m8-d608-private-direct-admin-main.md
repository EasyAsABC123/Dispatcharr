# Private direct administrator Main on d608ff75

A private d608-derived package completed the same ordinary eight-request
administrator navigation as pinned Original. Both entered at /admin,
authenticated from the returned masked CSRF form, followed the index and
Core Settings links to the owned row, read it, and logged out. The signed
PostgreSQL session, unchanged settings and unrelated rows, and exact
session deletion were verified.

The Rust Main used the stock development selection with an unpublished
loopback listener. After it retired, a fresh normal AIO-mode Main from the
same image returned 301 to /login on /admin/login/ with no session cookie.
Both exact Main generations exited 0 and the owned Compose inventories
were empty.

The image compiled and exported on the first attempt. Its attestation
controller exited 1 while reading the optional OCI Cmd field. Read-only
attestation accepted the omitted field as the empty command and verified
the exact index, AMD64 manifest and config without rebuilding. The replay
used the same compiled image.

This package remains a private fixture. Packaged production direct
ingress, the broader Django administrator surface, full M8 and performance
remain open. See the earlier [HTTP navigation proof](rust-m8-a33cf4cc-admin-http-navigation.md)
and [SQLx session proof](rust-m8-a33cf4cc-admin-session-sqlx.md).
