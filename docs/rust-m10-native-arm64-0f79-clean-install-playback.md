# Native ARM64 clean install and playback on 0f79

The private image assembled all nine components and verified the hashes, byte sizes, and timestamps of 27 pinned DRF static files as UID 65532. All ten normal clean-install checks passed on the exact Rust application `0f79dc28f8718a05a6b28dc554be958e3e295b47`. They covered an empty PostgreSQL database, the initialization-off control, schema creation, the React index, first-admin setup and login, and a restart preserving schema while keeping setup closed. HTTP used the runner's owned internal bridge without publishing a host port. [Machine-readable evidence](../scripts/rust-integration/m10-native-arm64-0f79-clean-install-playback.json)

The overlay correction completed both playback checks. Two ordinary authenticated readers shared one active origin connection. Each reader supplied MPEG-TS bytes that decoded as audio and video. The origin returned to zero active connections with one lifetime connection. The runner verified exact removal of the test Compose resources and private candidate image. [Exact hosted retry](https://github.com/EasyAsABC123/Dispatcharr/actions/runs/44892036200/job/136809763466)

The earlier attempts retain their literal exit 1 results. The static metadata fix allowed Main to listen in the second attempt, whose host port lookup timed out. The internal-bridge correction then passed all ten install checks. Playback stopped in that third attempt when the controller queried the synthetic media service without its Compose overlay.
