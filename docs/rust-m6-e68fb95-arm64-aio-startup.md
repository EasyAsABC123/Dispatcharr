# Ordinary AIO startup on ARM64 e68fb95

The original Dispatcharr and Celery authors and contributors retain full credit. See [Attribution](../ATTRIBUTION.md).

Two separate Lappy Compose projects ran the exact ordinary e68fb95 package with the AIO environment and no ownership overrides. The role fixture showed ready Selected workers for both queues, their subscribed control channel, seven persisted schedule contracts and a natural scan tick from count 0 to 1. It verified four owned role retirements.

The downstream fixture observed one owned local Version request, the resulting administrator notification, and both real Version and empty recording Recovery task terminals. It verified five owned role retirements. The native processes and both controllers exited 0.

Two first attempts stopped during image admission before provisioning. Docker's unpinned platform-inspection result could report the index where the verifier expected its ARM64 child. The passing checks bound both exact descriptors and retained their layer, source, user and entrypoint checks. Wider AIO jobs, complete M6, and comparative performance remain open.
