# Opt-in unsigned plugin manifests

The Rust PluginRepo library now has an explicit unsigned-manifest constructor.
It supports the measured literal-IP, plain-HTTP, UTF-8 JSON context for preview,
create and refresh. The default metadata constructor and Main remain unchanged.
HTTPS, hostname/DNS resolution, URL credentials, compression, chunked transfer,
signed manifests/GPG and unmeasured fault rendering remain guarded or unqualified.

Two fresh Native contexts passed 24 retained Source cases and a separate real
fetch-404 case. Status, selected headers, parsed JSON, stable SQL, all 59 sequence
effects, request clock relationships, decoded settings-cache effects and unrelated
Redis bytes match their Source references. Raw response bytes match 21 of the
24 cases; three responses contain newly generated dates. Cache serialization
bytes differ and are not relabeled as equal.

Two further Native tests passed with actual upstream reply bytes held: cancelled
router observer during headers and a borrowed 100 ms observer deadline during
the body. The same original writer permit remains held across two samples at
least 250 ms apart. Actual native descriptor/socket-generation observations show
that generation absent after drop while the permit is still held. A real response
clone retains the permit, and final retirement restores four slots. These tests
do not establish frontend TCP-disconnect behavior, all possible socket duplicates,
late SQL Ready ownership or four concurrent new-fetch response frames.

not a fetch-404 case; the separate one-request reference captures that branch.
None of these failures is relabeled. Input reconstruction, dependency notices,
raw observations, finite projection rules and 37 corruption controls are included.
