# d6be native ARM64 package and inventory hold

Lappy built the d6be ordinary Linux ARM64 image. The child build and signed authentication smoke both exited 0. Packaged Main returned readiness and React HTML HTTP 200 on aarch64. The runtime notice checks passed, and all five owned containers, the network, and the volume retired.

The overall package owner exited 1 at its shared-engine inventory check. Two closing inventories agreed with each other. Their network identity set differed from the opening set, while the container and volume sets matched. All three samples reported seven stopped containers, zero running containers, five networks, and 16 volumes. The independent full package audit was skipped.

The [typed audit](rust-d6be0944-arm64-packaging-and-inventory-hold.json) preserves the child results and the overall refusal. The bounded engine events verified the owned network lifecycle. They leave the source of the shared-engine identity change unresolved. ARM64 release acceptance remains on hold.
