Original Dispatcharr, Celery and dependency authors and contributors retain full credit. See [upstream attribution](../ATTRIBUTION.md).

The exact native ARM64 package started with `DISPATCHARR_ENV=aio` and no queue-role overrides. The fixture tied the two live startup publication IDs to their actual Redis terminal results. Version and recording recovery each reached SUCCESS with zero children. A local isolated Version endpoint received one request, and PostgreSQL retained the expected active administrator notification for the fixture version. Recovery returned `Recovery complete` on the empty owned dataset.
