# Paired React account workflows on ARM64 f960875

The original Dispatcharr and React authors and contributors retain full credit for the application. See [Attribution](../ATTRIBUTION.md).

Installed Chromium drove the same exact baked React assets against both the pinned Original and the ordinary Native ARM64 backends. Each browser started from an empty owned database and reached the setup form, created one initial administrator using the normal form, signed in, rendered the authenticated channel page, read the account dialog and signed out.

Both controllers returned 0. Each left one active administrator in the intended scoped state and verified browser profile retirement and exact Compose cleanup. The fixture observed zero blocked off-origin requests. Earlier port admission and form observer timeouts stayed recorded with their original exits.

The [machine-readable proof](../scripts/rust-integration/m5-f960875-arm64-account-browser-pair.json) binds both browser results to their package and observer digests. The shared fixture origin serves the identical React build and proxies the scoped backend requests. Broader UI workflows, packaged static-file routing across every path, and complete M5 parity remain open.
