# M5 Single Create Channel from Stream

The original Dispatcharr and Django authors retain full credit.

The existing React Streams form can create one channel through packaged Rust Main. In a fresh, isolated Docker Compose comparison, pinned Original and Rust revision `8a821e27adb01df52898e971661a20a9362c54a1` each returned four typed HTTP 201 responses and matching detail reads. The cases used the provider number, the first free number, the next number after the highest reserved number, and the next number after an explicitly selected reserved number. The fixture checked effective and stored numbering, the exact stream link, all/specific/no profile membership, stream-derived fields, and a local dummy Guide match. It also received the exact `channels_created` update through the configured Channels subscriber for each create.

Each backend then created, fetched, renamed and deleted one ordinary manual channel through the generic API, with results 201, 200, 200 and 204. The fixture checked the linked stream and profile, verified that the rename changed only the selected row fields, and confirmed the delete restored the scoped rows. Both started from matching scoped PostgreSQL snapshots. The controller exited 0 and verified all four owned role generations retired and no project containers, volumes or networks remained.

This result covers the four normal Streams form cases and the generic channel CRUD regression. Full M5 and performance verification remain open.
