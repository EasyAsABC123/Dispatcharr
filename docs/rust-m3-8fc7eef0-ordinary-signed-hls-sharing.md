# AMD64 two-viewer signed HLS sharing on 8fc7eef0

Pinned Original and the exact packaged Rust build served distinct authenticated HLS sessions for two simultaneous viewers of the same FFmpeg OutputProfile stream. Both viewers received valid playlists and the same bytes for MPEG-TS segments 2 and 3. All four retained captures matched across backends and passed strict FFmpeg decoding. Each capture contained 100 H.264 video frames and 192 AAC audio frames. The two viewers in each backend shared one physical FFmpeg profile process and one upstream connection. Both stop requests returned HTTP 204, the exact profile process and upstream retired, and both Compose projects verified teardown. Rust Main exited 0 without OOM. This verifies healthy signed HLS sharing on AMD64. M3 and its performance gate remain open.
