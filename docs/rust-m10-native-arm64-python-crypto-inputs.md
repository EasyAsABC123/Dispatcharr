# Native ARM64 Python and crypto collector inputs

The hosted read-only retry examined the exact Original Dispatcharr ARM64 donor under UID 65532 with network access disabled. CPython 3.13.18, its regex extension, and GPG were AArch64 ELF inputs. The donor loader resolved 5, 3, and 12 linked paths respectively. Each linked path had an observed installed package notice, and the regex extension had its installed wheel notice. GPG 2.4.8 was a regular file. Certifi 2026.10.23 supplied the expected trust bundle and explicit license path. [Hosted retry](https://github.com/EasyAsABC123/Dispatcharr/actions/runs/44873672071)

All 15 selected Python distributions were present. The retry counted 90 Torch notice candidates, above its 64-file projection limit, and left that notice inventory unresolved. The ARM64 Torch 2.14.1+cpu development shim was 688,016 bytes with SHA-256 `7a6ed5a36b82b29aa78469736dca7b9ba36f8534bf40c7c30291d4c5339f86ba`. The current AMD64 exclusion expects 630,280 bytes and a different digest. ARM64 needs its own reviewed exclusion preimage. Tokenizers 0.23.3 had zero installed notice candidates. The collector has separate exact-version upstream text for this version, which this donor probe did not copy or verify as part of a relocated image.

The first run exited 1 during Python distribution inspection and emitted no inventory. Its log identified only the broader distribution phase. The retry exited 0 and preserved the unresolved Torch notice result. Both controllers verified retirement. This scope covers donor inputs. Python callback execution, private-loader relocation, GPG operation, integrated ARM64 Compose, and distribution qualification remain open.
