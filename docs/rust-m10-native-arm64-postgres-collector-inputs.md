# Native ARM64 PostgreSQL collector inputs

A native ARM64 GitHub runner inventoried the pinned public Original
Dispatcharr donor as UID 65532 in an isolated, read-only container. It
verified the actual AArch64 PostgreSQL 17.11 `pg_dump`, `pg_restore`,
and `psql` clients and their installed loader. The inventory covered
26 shared libraries, including four NSS entries, one separately
loaded OpenSSL provider, and 475 public PostgreSQL support files.
Twenty installed packages provided original copyright notices. The
guest and controller exited zero. The exact container retired and
the owned inventory was empty.
[Hosted run](https://github.com/EasyAsABC123/Dispatcharr/actions/runs/44870617035)

The inventory records donor inputs for the PostgreSQL client collector.
The guarded restore helper, standalone Debian client wrapper runtime
and full ARM64 application package have distinct proof requirements.
Corresponding-source and distribution qualification remain open.
