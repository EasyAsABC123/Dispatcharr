# Cold and warm scheduler installation on f960875

The original Dispatcharr authors and contributors retain full credit for the application. See [Attribution](../ATTRIBUTION.md).

Original and ordinary Native each installed the same six known-default schedules in an owned empty scheduler roster. On the warm restart, both repaired the Stats schedule and preserved the other five defaults and the unrelated dormant row. Neither arm published a broker task during the observed window. The independent evaluator checked the persisted PostgreSQL rows and broker journal, and both physical arms verified exact retirement.

Original completed in the preceding run. Native in that run stopped before HTTP readiness because the disposable fixture had created its EPG cache under the wrong UID. After the fixture initialized only its owned volume for the packaged process UID, Native passed the cold and warm runs on the same f960875 image. Its independent proof used the retained completed Original arm and records that only Native was physically rerun.

The [machine-readable proof](../scripts/rust-integration/m6-f960875-cold-warm-scheduler-install.json) covers the full known-default installation workflow in a bounded one-row rehearsal. The official release matrix and wider M6 scheduler workflows remain open.
