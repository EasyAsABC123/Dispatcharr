# Private Native administrator settings Save and web restart

A private Linux AMD64 Rust Main image derived from application 2581d75b
completed the same ordinary Save and restart workflow as the separately
qualified Stock fixture. One same-origin client signed in, followed the
Core Settings links, submitted the real masked-CSRF Save form for a
preseeded inert setting, followed the list redirect and reread the
changed JSON. The edit added one Django-format change audit row. The
scoped cache entry invalidated, its version advanced during Save and a
separate cache control stayed intact.

The Compose owner stopped the first direct Main, observed the closed
loopback listener and started a second direct Main from the same image
with the same setting scope. PostgreSQL and Redis kept their generations.
The same signed session still authenticated, the saved JSON and one audit
row persisted, and the readback introduced no scoped SQL writes. Normal
logout removed the same session. The cache version and control remained
stable across the restart.

The direct generations published no host ports. The image config runs as
UID and GID 65532 and leaves both private edit settings unset. A separate
AIO generation from the same image returned 301 from `/admin/login/` to
`/login` with no session cookies. All three Main generations exited zero.
The four owned Compose roles and their exact generations retired with
zero remaining project containers, networks or volumes.

The cookie jar ran the twelve ordinary HTTP calls without rendering a
browser. This fixture covers one inert setting with an explicit private
selection. General admin coverage, public deployment, cache failure
ordering, full M8 and performance remain open.
