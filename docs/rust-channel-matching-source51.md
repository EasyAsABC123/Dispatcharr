# Channel matching: Source51 authority and private Rust decisions

Original Dispatcharr, Celery, Django, CPython, RapidFuzz and dependency authors
retain full application, protocol and algorithm credit. React is unchanged.

The fresh pinned Original cohort passed all 14 natural HTTP matching cases in
149.562 seconds, with actual exit 0, both pipe EOFs and an empty process group.
[Qualification](../scripts/rust-integration/channel-matching-source51/Source51/qualification.json)
records one Source context, not 14 independent application launches. Independent
cleanup verified both exact fixture containers, their Compose project resources
and both original positive host PIDs absent. No Native matching application or
performance gain follows from this Source result.

The [case projections](../scripts/rust-integration/channel-matching-source51/Source51/cases.json)
cover the actual all-unassigned, selected and single-channel POST actions. All
returned HTTP202 and queued their real Celery roots; the helper did not call a
backend task body. Thirteen roots completed with SUCCESS. The deliberately
injected selected-channel SQL failure completed with FAILURE, while the single
wrapper caught the same database refusal and returned its ordinary failure
result with backend SUCCESS. Following work continued. Those distinct Source
error semantics remain part of the contract.

| Workflow | Observed Source behavior |
| --- | --- |
| All/selected exact matching | TVG/Gracenote IDs, active-source filtering, priority, assigned-channel exclusion/inclusion, changed and unchanged associations, and an empty selected queryset |
| Single exact and fuzzy | Exact lookup uses the first database ID, including nameless entries; fuzzy selection considers priority. No-match and settings-aware normalization remain separate results. |
| Catalog and region | Bulk catalog excludes nameless entries; inactive rows cannot win. The legacy flat `preferred-region` key supplies the region bonus, rather than Core's newer grouped getter. |
| Assignment effects | Bulk mixed XMLTV/SD/dummy assignment publishes XML parsing then one SD batch at the threshold. Single SD assignment publishes direct parsing, invalidates the output-cache generation and marks the manual group custom. |
| Progress and ownership | Actual updates-group messages, root/backend identity, child parent/root IDs and terminal results were captured through the existing bounded observer and durable database1 journal. |

The [pure observations](../scripts/rust-integration/channel-matching-source51/Source51/vectors.json)
come from the pinned image's CPython3.13.18, Unicode15.1.0 and RapidFuzz3.14.6.
They preserve 38 normalization value/error observations and 80 threshold decisions
using explicitly supplied test cosine scores, plus ratio, region, priority/top20
and settings-cache observations. No model inference is represented by those
supplied scores. Source discards non-list ignore settings and skips non-string
entries; falsy names return empty, while truthy non-string names raise
AttributeError. Prefix/suffix order, multiline regex behavior, contextual Greek
lowercasing and Unicode word classes are retained in the vectors.
