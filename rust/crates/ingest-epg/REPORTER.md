# Guide import effects

Original Dispatcharr authors and contributors retain all application and algorithm credit.

`GuideReporter` and `EpgImporter::import_file_reported` are an incremental, app-unwired guide-job component. The ordinary importer methods continue without publication/status effects. They use the same owned parser, staging and cancellation boundaries.

Reported imports publish initial progress 0, parsing progress 10 after the open descriptor passes the footer check, a progress tick for every 5,000 accepted programmes after the corresponding staging reply, and progress 90 before late policy lookup and swap. No-map success stores only status/message and preserves `updated_at`; it skips parsing, invalidation and audit. Successful swaps retire XMLTV chunks by incrementing the original raw generation key, save status/message and a microsecond-precision timestamp, write the original audit fields, then publish progress 100. Invalidations and audit/publication failures retain the original best-effort behavior. Missing-file/no-URL and incomplete-footer branches preserve their distinct stored and published error messages, with error publication preceding audit.

The reporter has at most four physical operations (configured 1–4), limits owned message text to 64 KiB per operation, and supervises SQL/publication work independently of its awaiting caller. Admission and the caller's retained job context pass through actual Redis replies, including logical command timeouts. Shutdown reports false while physical work remains and does not abort it. The production `RealtimeBus` implements the retained sink entrypoint; custom sinks must retain the supplied guard through any detached work. The original unbounded publication path is not a claim about native capacity outside the configured limits.

System-event retention reads the original full grouped `system_settings` cache through retained, bounded Redis/SQL operations. This reuses the existing restricted Django cache codec and version fencing, and retains the original cutoff-row/off-by-one semantics. Its complete default map is pinned to the tested original UTC environment; other deployment defaults need a separate fixture.

Source characterization is reproducible using `scripts/rust-epg-parity/run_reporter.py`; add `--native` for the frozen native importer/reporting and actual blocked-SQL ownership tests. The runner captures source/tool hashes before fixture setup, raw original effects, the native archive, and cleanup. It excludes the Python-injected swap-error case from native automatic import comparison: SQL exception spelling/recovery remains a separate gate. Source 53 and the failed native 54 artifact are retained; 54 exposed missing fixture restoration between resource and differential tests rather than a runtime status correction.

Remaining work includes download/extraction/path resolution, arbitrary parser/SQL exception formatting and terminal-status recovery, status/save failures, full event-history retention cases, source deletion during a job, actual WebSocket delivery for this producer, external Connect/plugin dispatch, late-mapping task dispatch, retries/scheduling/completion, app wiring, and isolated job resource/performance acceptance. These components do not establish complete guide refresh parity.

The final component gates passed at `m6-guide-reporter-source-native-56`, with identical frozen runtime regressions `m6-reported-import-backcompat-source-native-57` and `m6-retained-multigroup-policy-source-native-58`. They cover eight import producer cases, two physical SQL ownership/order scenarios, both a stored partial system map and empty-DB full defaults, 15 prior file import cases, 18 prior cache cases, ten unit tests and strict Clippy. The full nine-key native default cache was decoded by the original Django runtime.

`m6-guide-reporter-component-docker-60` repeats the reporter cases in a nonroot, read-only Compose service capped at 512 MiB, two CPUs and 128 PIDs. Its image preserves all 379 accepted runtime files from gate 56; only separate test packaging and original author/license notices are added. Durable summaries are `verified-reporter-source-native-56.json` and `verified-reporter-component-docker-60.json` under `scripts/rust-epg-parity`. These remain component acceptance, with the orchestration/transport gaps above open.
