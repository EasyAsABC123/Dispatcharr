# Indexed current-programme file reader

All application and algorithm credit belongs to the original Dispatcharr authors and contributors.

`current_file::read_current_file` ports the original `_read_programs_at_offsets` and interleaved `_scan_from_offset_for_tvg_id` helpers. It reads the supplied regular-file descriptor in 2 MiB chunks. Block reads stop at another decoded channel; interleaved reads skip other channels. A strict single-element parser validates each fragment before the original start/stop checks. The returned title, description and subtitle preserve direct leading text and whitespace. Invalid timestamps propagate their original error class; malformed XML fragments are skipped. The interleaved deadline is checked at the original outer-loop boundary.

Frozen96 compares 54 actual original-helper outcomes, including chunk-boundary splits, raw comment/tag matching, channel entity decoding, namespace/text behavior, invalid timestamps and offset/forward fallback. Three additional native file/resource tests check descriptor stability after atomic replacement, cancellation before seek/read, and retained-buffer/aggregate-read limits. See `scripts/rust-epg-parity/verified-current-file-source-native-96.json` for captured sources and checks.

The default support envelope is an 8 MiB retained read buffer, 256 MiB aggregate reads, ten offsets and a ten-second forward deadline. Configured buffers may reach 16 MiB, aggregate reads 4 GiB, and offsets 100. Strict fragments remain subject to the strict parser's 4 MiB input and 16 MiB native heap limits. Exceeding a limit produces an explicit resource error; this does not establish parity for arbitrarily large valid Source input. The caller must reserve memory and keep worker/file guards until the synchronous operation physically returns.

This component does not load the index, resolve source paths, sample fresh clocks, queue a missing index, supervise asynchronous callers or implement the current-programme HTTP fallback. Those require separate actual PostgreSQL, cancellation, concurrent-refresh and application gates. No performance gain follows from this component proof.

Frozen98 additionally validates `read_current_with_opener`: it closes the offset helper's file and calls its factory again for an interleaved forward scan. The existing descriptor API retains its accepted behavior. All 65 Source/native cases pass, including six controlled replacement/deletion/open-count cases and the original upstream's description larger than 2 MiB in both offset/forward paths. Its 22 frozen native tests and strict all-target Clippy pass. See `verified-current-file-source-native-98.json`. This helper proof does not accept the still-unregistered SQL lookup service or application integration.
