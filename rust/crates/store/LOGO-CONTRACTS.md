Logo list/retrieve require an active Standard-or-higher account and UI network permission. Serialization exposes id/name/url, absolute cache URL with the original eight-character MD5 version, total channel count, usage flag and first five channel names plus the original remaining-count string. Channel names/counts include all direct logo relationships without user channel-profile filtering. Repeated `ids` parameters follow Python Unicode15.1 `isdigit()` before `int()`. Non-digit strings, negative values and empty strings are ignored; all-invalid values leave the query unfiltered. A digit-only string containing a non-decimal digit, such as superscript two, makes the queryset empty. The captured original digit table preserves that distinction, including decimal digits outside ASCII. `used` accepts only exact true/false; name filtering is case insensitive. Numeric unknown/filtered details and malformed identifiers have different original404 messages.

Stream filter choices preserve the original hierarchy and its fast-path quirks. With none of name/provider/provider-name/provider-active/tvg-id filters present, the original ignores custom/search/group filters and returns options from streams whose provider is not inactive. Otherwise group filters are removed for both option lists, and provider IDs are additionally removed for provider choices. DRF search is absent from the action. Null group/provider relationships are omitted from their respective options.
